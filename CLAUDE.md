# CLAUDE.md

This file provides guidance to Claude Code when working with code in this repository.

## İletişim
Türkçe konuş. Kısa ve öz cevaplar ver. Önce sonucu söyle, gerekirse kısa bir açıklama ekle.

## Çalışma stili

- Minimum değişiklik yap. Dosyanın tamamını yeniden yazmak yerine sadece gerekli kısmı düzenle.
- Büyük görevleri küçük adımlara böl; her adımdan sonra bir sonraki kritik adımı öner.
- Hata ayıklarken önce kök nedeni bul, belirsizse bir kısa soru sor.
- Adım adım açıkla, acele etme, hataları söyle.

## Proje: Kegel Max — Pelvik Güç

Mobile-first web uygulaması. Next.js + TypeScript + Tailwind CSS + PostgreSQL.

### Geliştirme komutları
- `npm run dev` — geliştirme sunucusu
- `npm run build` — production build
- `npm run lint` — lint kontrolü

### Kurallar
- Dark mode öncelikli UI tasarımı
- Mobile-first, telefon tarayıcısından açılır
- Privacy-first yaklaşım (hassas içerik)
- TypeScript strict mode
- Tailwind ile stil, harici CSS dosyasından kaçın
